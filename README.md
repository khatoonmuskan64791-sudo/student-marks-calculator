# Student Marks Calculator 🎓

A beginner-friendly student project built using **HTML, CSS, and JavaScript**. It calculates total marks, percentage, grade, and pass/fail status.

## Features
- Enter a student name.
- Choose from 3 to 8 subjects.
- Enter marks from 0 to 100 for each subject.
- Calculate total marks and percentage automatically.
- Display a grade and pass/fail status.
- Responsive layout for mobile and desktop.
- Reset the form to calculate another student's result.

## Grade rules
| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–89.99% | A |
| 70–79.99% | B |
| 60–69.99% | C |
| 50–59.99% | D |
| 35–49.99% | E |
| Below 35% | F |

**Pass rule:** The student must score at least 35 marks in every subject. Each subject is assumed to be out of 100. These rules are sample rules and can be changed to match your institution.

## How to run
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.

No installation or server is required.

## Files
- `index.html` — page structure and form
- `style.css` — design and responsive layout
- `script.js` — marks calculation and grade logic

## Publish with GitHub Pages
1. Upload all project files to your GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for deployment and open the URL shown in the Pages section.

## Introduction
This project demonstrates basic web development and arithmetic calculations in a practical student-friendly application.

## Advantages
- Saves time compared with manual calculations.
- Makes results easy to read.
- Helps beginners practise HTML, CSS, JavaScript, form validation, and DOM updates.

## Limitations
- Uses a sample grading scale.
- Does not save student results after the page is closed.
- Does not include login, a database, or report export.

## Conclusion
The Student Marks Calculator is a simple project for learning front-end development and can later be expanded with student records, PDF reports, or database storage.
